# Diamond Row

Кроссплатформенная 2D-игра в жанре **Match-3 («Три в ряд»)** на Java с использованием фреймворка **libGDX**.
Графика игрового поля, кристаллов, иконки и пользовательского интерфейса формируется программно через `ShapeRenderer`, `Pixmap` и `BitmapFont` без сторонних графических ассетов, а лучший результат сохраняется локально через `Preferences`.

## Об игре и механиках

- **Игровое поле:** сетка размером `8×8` ячеек, заполненная цветными алмазами (`Gem`). При старте поле формируется так, чтобы не было готовых линий из трёх и более одинаковых элементов.
- **Управление:** поддерживается клик по двум соседним клеткам или свайп/перетаскивание мышью на ПК и тап/свайп пальцем на сенсорных экранах.
- **Механика Match-3 и комбо:**
  - Менять местами можно только соседние по горизонтали или вертикали алмазы.
  - Если обмен образует ряд из `3` и более одинаковых алмазов по горизонтали или вертикали — совпадение засчитывается, за каждый разрушенный алмаз начисляется `+10` очков.
  - Если комбинация не образовалась — алмазы плавно возвращаются на исходные позиции (`REVERTING`).
  - После очистки алмазов верхние элементы осыпаются вниз (`FALLING`), пустые клетки сверху заполняются новыми алмазами, а новые образовавшиеся совпадения запускают цепные реакции (каскады).
- **Уровни сложности:**
  - **Уровень 1:** цель `200` очков за `20` ходов.
  - **Уровень 2:** цель `500` очков за `25` ходов.
  - **Уровень 3 и далее:** бесконечный режим (`ENDLESS MODE`) без ограничения по ходам и целевым очкам.
- **Управление состоянием игры:**
  - Кнопка `STOP` в правом верхнем углу переводит игру в режим паузы (`PAUSED`) и открывает меню с кнопками `RESUME` (продолжить) и `EXIT` (выход из приложения).
  - При исчерпании ходов до набора нужных очков открывается окно `GAME OVER` с итоговым счётом и кнопкой `RESTART`.
- **Рекорд (`BEST`):** автоматически сохраняется в локальном хранилище устройства через `Gdx.app.getPreferences(...)`.

## Как скачать и запустить игру

Готовые сборки публикуются в разделе **Releases** репозитория:
`https://github.com/<ВАШ_НИК>/<НАЗВАНИЕ_РЕПОЗИТОРИЯ>/releases`

### Windows (.exe из Releases)

1. Перейдите во вкладку **Releases** на GitHub и скачайте архив с Windows-сборкой (например, `DiamondRow-windows-x64.zip`).
2. Распакуйте архив в любую удобную папку на компьютере (важно не вытаскивать `DiamondRow.exe` отдельно от соседней папки `runtime`, так как в ней находится встроенная среда выполнения Java).
3. Запустите `DiamondRow.exe` двойным кликом. Отдельная установка Java пользователю не требуется.

### Android (.apk из Releases)

1. Откройте страницу **Releases** на GitHub со смартфона (или скачайте `.apk` на ПК и перенесите на устройство).
2. Скачайте файл `.apk` (например, `android-debug.apk` или релизный `.apk`).
3. Откройте загруженный файл. Если Android запросит разрешение на установку приложений из этого источника (браузер или файловый менеджер) — разрешите её в настройках и завершите установку.
4. Запустите **Diamond Row** из меню приложений.

### iPhone / iOS

Напрямую скачать и установить сторонний файл на обычный iPhone из GitHub обычным пользователям нельзя из-за политики безопасности и цифровой подписи Apple.
- **Локальный запуск при разработке:** проект в модуле `ios` собирается локально на компьютере с **macOS** и установленным **Xcode** (для запуска на симуляторе или подключённом по кабелю/локальной сети устройстве разработчика).
- **Распространение для пользователей:** требует аккаунта **Apple Developer**, формирования подписанного `.ipa` и публикации через **TestFlight** или **App Store**.

## Как работает код

### Архитектура модулей

Проект организован по модульной структуре libGDX:
- `core/` — платформонезависимая логика игры, отрисовка, состояния и работа с сеткой (`DiamondGame`, `Board`, `Gem`).
- `lwjgl3/` — точка входа для десктопа (`Lwjgl3Launcher`), настройка окна, генерация иконки и запуск `Lwjgl3Application`.
- `android/` — точка входа для Android (`AndroidLauncher`) и ресурсы приложения.
- `ios/` — точка входа для iOS (`IOSLauncher`).

### Главный цикл и конечный автомат состояний (`DiamondGame.java`)

Класс `DiamondGame` наследует `ApplicationAdapter` и управляет жизненным циклом игры:
- `create()` — инициализирует ортографическую камеру и `FitViewport` (`480×800` виртуальных единиц, чтобы пропорции сохранялись при изменении размера окна/экрана), объекты `ShapeRenderer`, `SpriteBatch`, `BitmapFont` и `Preferences`, загружает `highScore` и запускает 1-й уровень.
- `render()` — на каждом кадре получает `delta` (время между кадрами), обновляет игровую логику (если игра не на паузе), очищает экран, отрисовывает доску, кристаллы и интерфейс (`drawBoardAndGems()`, `drawUI()`).
- **Состояния (`enum State`):**
  - `IDLE` — ожидание действия игрока (выбора или свайпа алмаза либо нажатия `STOP`).
  - `SWAPPING` — анимация обмена двух соседних алмазов местами; после завершения проверяются совпадения (`findMatches()`). Если совпадений нет — запускается обратный обмен (`REVERTING`).
  - `REVERTING` — возврат двух алмазов на исходные клетки при неудачном ходе.
  - `FALLING` — пауза на подсветку/удаление совпавших алмазов (`matchTimer`), затем осыпание столбцов и заполнение новыми элементами (`collapseAndRefill()`) с проверкой каскадных совпадений.
  - `PAUSED` — остановка игрового обновления (`updateLogic` не вызывается) и показ меню `RESUME` / `EXIT`.
  - `GAME_OVER` — экран завершения игры с кнопкой `RESTART`.

### Управление и обработка ввода

Ввод обрабатывается через `InputAdapter`, назначенный в `Gdx.input.setInputProcessor(...)`:
- Координаты клика/касания переводятся из экранных в мировые координаты игры через `viewport.unproject(...)` — благодаря этому хитбоксы кнопок и клеток доски работают точно независимо от масштаба окна.
- В `touchDown(...)` сначала проверяются модальные состояния (`PAUSED`, `GAME_OVER`), затем кнопка `STOP` (`x: 365..455, y: 735..780`), а далее вычисляются индексы строки и столбца (`row`, `col`) на доске.
- Поддерживаются два сценария обмена:
  1. **Клик/тап:** выбор первого алмаза и клик/тап по соседнему алмазу (`isAdjacent(...)`).
  2. **Свайп/перетаскивание:** в `touchDragged(...)` отслеживается смещение (`dx`, `dy`) от точки нажатия; при превышении порога (`CELL_SIZE * 0.4f`) определяется направление по большей оси и инициируется обмен с соседней клеткой.

### Игровое поле, поиск совпадений и каскады (`Board.java` и `Gem.java`)

- `Gem` хранит тип/цвет кристалла, целевые координаты в сетке, визуальные координаты (`visualX`, `visualY`) и масштаб (`scale`), что позволяет плавно интерполировать движение и анимацию исчезновения в `update(delta)`.
- `Board` хранит двумерный массив `grid[row][col]` размером `8×8`:
  - При создании доски случайные алмазы подбираются так, чтобы избежать стартовых комбинаций из 3 в ряд.
  - `findMatches()` сканирует горизонтальные и вертикальные последовательности одинаковых элементов длиной от `3` и помечает совпавшие клетки к удалению, возвращая количество найденных элементов.
  - `collapseAndRefill()` сдвигает оставшиеся в столбце алмазы вниз на освободившиеся места и создаёт новые алмазы сверху.

### Сохранение рекордов и генерация иконки (`Lwjgl3Launcher.java`)

- **Рекорды:** при начислении очков (`addScore`) значение `score` сравнивается с `highScore`; при улучшении результата новое значение записывается в `Preferences` (`DiamondRowPrefs`) и сбрасывается на диск через `prefs.flush()`.
- **Иконка на ПК:** в `Lwjgl3Launcher.main(...)` сначала вызывается `Lwjgl3NativesLoader.load()` для загрузки нативных библиотек libGDX, затем метод `createTempDiamondIcon(64)` рисует иконку алмаза на `Pixmap`, сохраняет её во временный `.png` через `PixmapIO.writePNG(...)` и передаёт в `config.setWindowIcon(Files.FileType.Absolute, iconPath)`.
